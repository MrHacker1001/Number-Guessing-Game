# 🔢 Number Guessing Game

A simple Python terminal game that chooses a secret number between **1 and 100** and asks you to guess it.

## 🧰 Built With
- Python 3
- `random` module

## ▶️ Run the Game

Make sure Python 3 is installed, then run:

```bash
python main.py
```

## 🎯 How to Play
1. Start the game in your terminal.
2. Enter a number when prompted.
3. Follow the hints to adjust your guess.
4. Keep guessing until you find the secret number.
5. The game tells you how many attempts you used.

## 📚 Concepts Practiced
- Random number generation
- `while` loops
- User input
- Counters and f-strings
- Conditional statements
